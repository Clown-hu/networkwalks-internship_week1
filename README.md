# networkwalks-internship_week1

This repository contains the documentation and screenshots for my Week 1 tasks in the Cybersecurity Internship Program at NetworkWalks.

📁 1. Lab Setup (VirtualBox)

For this project, I successfully built a virtual cybersecurity lab environment using **Oracle VirtualBox**. Steps completed:

✔️Network Configuration:** Created a NAT Network with the subnet `10.0.0.0/24` to ensure isolated communication.

✔️Kali Linux Configuration:** Imported and configured Kali Linux, assigning it a static IP address of `10.0.0.3`.

✔️Connectivity Test:** Verified full internet access from the VM by successfully pinging Google's DNS (`8.8.8.8`).

✔️Shared Folders:** Enabled a shared folder between the host machine and Kali Linux for easy file transfer.

✔️Snapshot:** Took a VM snapshot (Lab Setup Complete) to preserve the working state for future tasks.
